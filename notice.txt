[Sunrise PDF Editor v3.2.2 업데이트 안내]

v3.2.1에서 v3.2.2로 업데이트되었습니다.

이번 v3.2.2는 v3.2.1의 온맵 성능/확대·축소 개선 기준을 유지하면서, 사용자가 요청한 여러 쪽 모아보기와 좌측 패널 조작성을 보완한 UI/보기 개선 버전입니다.

주요 업데이트
- 여러 쪽 모아보기 개선: Ctrl+4 또는 페이지 모아보기에서 3쪽 이상을 선택하면 기존처럼 가로로 길게 늘어나는 방식이 아니라 자동 격자 형태로 표시합니다.
- N-up 격자 배치: 4쪽은 2x2, 6쪽은 3x2, 9쪽은 3x3, 12쪽은 4x3에 가까운 균형 배치로 한 화면에서 문서 흐름을 확인할 수 있습니다.
- 폭맞춤/쪽맞춤 계산 보정: 여러 쪽 모아보기에서도 전체 한 줄 폭이 아니라 격자 행의 최대 폭과 전체 높이를 기준으로 배율을 계산하도록 수정했습니다.
- 좌측 기본 패널 닫기/열기 지원: 기존 기본 고정 탭이던 페이지, 레이어, 작업이력 패널도 사용자가 닫았다가 다시 열 수 있게 변경했습니다.
- 패널 열기 버튼 추가: 보기 탭의 좌측 패널 그룹에 페이지/레이어/작업이력 버튼을 추가하고, 페이지 탭의 이동 그룹에는 페이지 패널 버튼, 세션 탭의 작업이력 그룹에는 작업이력 패널 버튼을 추가했습니다.
- 패널 상태 복원 보정: 사용자가 닫은 기본 패널 상태가 다음 실행 때 임의로 되살아나지 않도록 좌측 패널 복원 로직을 수정했습니다.
- 검증 스크립트 추가: 여러 쪽 격자 보기와 좌측 패널 닫기/열기 회귀를 점검하는 v3.2.2 전용 audit를 추가하고 VERIFY.cmd에 포함했습니다.

안내
- 기존 v3.2.1 사용자는 v3.2.2 설치를 권장합니다.
- 업데이트는 강제 업데이트가 아니며, 설치 전 실행 중인 Sunrise PDF Editor를 종료한 뒤 진행해 주세요.
- AhnLab V3에서 클라우드 평판 또는 비인가 프로그램 안내가 표시될 경우, 배포 패키지의 AhnLab 제출용 정보와 함께 평판 검토를 요청할 수 있습니다.
