[Sunrise PDF Editor v3.2.7 업데이트 안내]

v3.2.5 안정 동작 기준에 문서 간 페이지 복사/붙여넣기 기능과 UI 정리를 반영한 v3.2.7입니다.

중요 변경
- v3.2.6에서 기본 ON으로 전환했던 온맵 atlas 및 온맵 자동갱신 기본값을 롤백했습니다. 실제 사용 환경에서 v3.2.5보다 온맵 조작이 느리고 원활하지 않은 사례가 확인되어, v3.2.7은 v3.2.5와 같은 수동/안전 기본 흐름을 사용합니다.
- SPE_ONMAP_LAYER_ATLAS 기본값은 0, SPE_ONMAP_AUTO_LAYER_PREVIEW 기본값은 0입니다. 필요한 경우에만 환경변수로 명시적으로 켤 수 있습니다.
- 여러 PDF를 동시에 연 상태에서 A 문서의 선택 페이지를 복사해 B 또는 C 문서의 PDF 맨 앞, 선택/현재 페이지 앞, 선택/현재 페이지 뒤, PDF 맨 끝에 붙여넣을 수 있습니다.
- Ctrl+C는 선택 페이지 복사, Ctrl+V는 붙여넣기 위치 선택 창으로 연결했습니다.
- 페이지 회전 UI는 중복 노출을 제거했습니다. 페이지가 선택되어 있으면 선택 페이지를 회전하고, 선택이 없으면 현재 페이지를 회전합니다.
- 각 기능에 맞는 로컬 SVG 아이콘을 보강하고 중복 단축키를 정리했습니다.
- 붙여넣기는 Undo/Redo 스냅샷과 연동되며, 붙여넣기 후 페이지 목록/렌더링/변경 상태가 즉시 갱신됩니다.

사용 안내
- 페이지 패널에서 복사할 페이지를 선택한 뒤 Ctrl+C 또는 페이지 리본의 [선택 페이지 복사]를 실행합니다.
- 대상 PDF 탭으로 이동한 뒤 Ctrl+V를 누르고 [PDF 맨 앞], [선택/현재 페이지 앞], [선택/현재 페이지 뒤], [PDF 맨 끝] 중 하나를 선택합니다.
