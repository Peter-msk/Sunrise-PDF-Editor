[Sunrise PDF Editor v4.6.1 정식 배포 안내]

Sunrise PDF Editor v4.6.1이 정식 배포되었습니다.
기존 v4.5.0 사용자는 새로운 문서 편집·변환 기능과 개선된 사용 환경을 이용할 수 있습니다.
v4.5.0 대비 문서 편집·변환 기능을 확장하고, 온맵 검토 및 원본 보호·작업 복구의 안정성을 높였습니다.

1. v4.5.0 대비 주요 기능 업데이트

- PDF 작성·편집: 빈 PDF 생성, 여러 페이지의 순서 변경·크롭·크기 조정, 페이지 삽입·추출·삭제·회전 등 편집 흐름을 보완했습니다.
- 병합·분할·추출: 링크·북마크·주석 등 문서 정보의 보존 검증을 강화하고, 복구 가능한 링크는 자동 처리하도록 개선했습니다. 복구할 수 없는 특수 링크는 사용자에게 안내합니다.
- PDF 압축: 화질 유지·균형·높은 압축 방식과 목표 용량 처리를 보완했습니다. 텍스트·이미지·링크·주석 및 온맵 OCG가 손상되지 않도록 결과 검증을 강화했습니다.
- 실무 작업센터: PDF 변환, 일괄 처리, 용량 기준 분할, 스캔 보정, PDF/A, 문서 비교 등 자주 사용하는 업무 기능으로 진입하는 흐름을 정리했습니다. 일부 기능은 별도 엔진이나 지원 환경이 필요합니다.
- 문서 검색·주석: 정확히 일치/대소문자 구분 검색의 위치 정확도와 검색 결과 하이라이트를 개선하고, 실패 시 Undo·복구 보호를 보강했습니다.
- 이미지·인쇄·내보내기: PDF/이미지 처리, 인쇄 가능 영역 맞춤, 출력 실패·취소 처리 및 기존 파일 보호를 개선했습니다.
- 온맵·대형 PDF: PDFium 기반 OCG 레이어 기능을 유지하면서 타일 캐시 무결성, 오래된 작업의 폐기, Native 렌더링·캐시의 불필요한 메모리 복사를 줄였습니다.
- 성능 개선: 검색용 페이지 분석 결과 재사용, 중복 이미지의 JPEG 인코딩 결과 재사용, 썸네일·타일 화면의 중복 갱신 감소로 처리 효율을 개선했습니다.
- 저장·복원·업데이트: 미저장 문서 종료 보호, 설정·세션 안전 저장, 업데이트 정보 검증 및 실패 복구를 보완했습니다. Sunrise Control v1 정책은 유지합니다.

2. 프로그램 주요 편의기능

- 다중 PDF 탭으로 여러 문서를 한 화면에서 전환하면서 작업할 수 있습니다.
- 페이지 썸네일로 긴 문서를 빠르게 탐색하고 페이지를 선택·재배치할 수 있습니다.
- 좌·우 작업 패널을 필요한 때 열고 접거나 복원할 수 있으며, 비어 있는 패널의 불필요한 확대를 제한합니다.
- 실무 작업센터에서 병합·분할·압축·변환·비교 등의 기능에 빠르게 접근할 수 있습니다.
- 텍스트 검색 후 해당 위치로 이동하고, 조건에 맞는 부분을 하이라이트할 수 있습니다.
- 대형 도면과 온맵 PDF에서 확대·이동 및 OCG 레이어 켜기·끄기를 지원합니다.
- 가능한 작업은 원본과 결과물을 분리 저장하며, 파일 덮어쓰기·저장 실패·취소 시 작업 보호를 우선합니다.
- Undo와 이전 작업 세션 복원 등으로 편집 실수를 줄이고 작업을 이어갈 수 있습니다.
- 병합·압축·추출 결과의 페이지·텍스트·링크·주석·레이어 보존 여부를 점검하도록 설계했습니다.

3. 정식 배포 및 사용 안내

- 배포 버전: Sunrise PDF Editor v4.6.1
- 주요 기능 업데이트 및 편의기능은 위 내용을 참고해 주세요.
- 업데이트는 프로그램의 기본 안내 절차에 따라 진행할 수 있습니다.
- 공지사항 및 업데이트 화면에서는 별도의 웹 주소 입력이나 링크 접속이 필요하지 않습니다.
