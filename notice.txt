[Sunrise PDF Editor v4.3.0 업데이트 안내]

Sunrise PDF Editor v4.3.0 시큐어디스크 호환 및 온맵 성능 보존 릴리즈입니다.

주요 변경
- 일반 로컬·네트워크 PDF는 기존 v4.0.1 온맵 고속 경로를 그대로 사용합니다.
- 일반 경로 개방이 차단된 문서에만 서명된 메인 프로세스의 읽기 전용 Secure Direct-Read 경로를 적용합니다.
- 파일 기반 메모리 매핑이 차단되는 환경은 ReadFile 기반 페이지파일 공유메모리로 폴백하며 PDF 디스크 복사본을 만들지 않습니다.
- Python 렌더 워커와 SunriseRenderHost는 원본 시큐어 경로를 다시 열지 않고 명명 공유메모리로 문서를 전달받습니다.
- 시큐어 문서의 레이어 상태 및 구조적 편집 결과는 AppData PDF가 아닌 현재 작업 문서의 메모리 스냅샷으로 렌더링합니다.
- 시큐어 모드에서는 PDF 자동저장, 디스크 타일 캐시, QtPdf 임시 PDF 및 레이어 Atlas PDF 생성을 차단합니다.
- 온맵 이미지 추출도 공유메모리 입력을 지원합니다.
- SunriseRenderHost는 support 구성요소로 동일 인증서 서명 대상이지만 3역할 릴리즈 게이트에는 포함되지 않습니다.
- DRM/DLP를 해제하거나 우회하지 않으며 회사 보안정책의 애플리케이션 허용 승인이 필요할 수 있습니다.
- 앱과 설치파일 버전은 4.3.0 / 4.3.0.0입니다.
