[Sunrise PDF Editor v3.2.0 업데이트 안내]

Sunrise PDF Editor가 v3.1.8에서 v3.2.0으로 업데이트되었습니다.

이번 v3.2.0은 일반 PDF 편집 기능의 안정성을 유지하면서, 온맵 PDF 처리 기능을 중심으로 성능과 사용성을 개선한 버전입니다.

주요 업데이트 내용은 다음과 같습니다.

1. 온맵 PDF 처리 개선
- 온맵 PDF 문서를 더 안정적으로 인식하도록 개선했습니다.
- 온맵 레이어 패널 표시와 레이어 켜기/끄기 동작을 보완했습니다.
- 레이어 상태 변경 후 미리보기 갱신이 더 안정적으로 동작하도록 개선했습니다.
- 대용량 온맵 PDF에서 미리보기 처리와 화면 갱신 흐름을 정리했습니다.

2. 온맵 이미지 추출 기능 강화
- 현재 레이어 상태를 기준으로 온맵 이미지를 추출할 수 있도록 개선했습니다.
- PNG와 JPG 저장 방식을 지원합니다.
- PNG 저장 시 두 가지 방식을 선택할 수 있습니다.
  - A안: PDF 원본 투명도와 알파 정보를 최대한 유지
  - B안: 흰 배경을 투명하게 처리하는 방식 강화
- JPG 저장 시 흰 배경으로 평탄화하여 저장되도록 처리했습니다.
- 300dpi 등 선택한 해상도 정보가 저장 이미지에 반영되도록 개선했습니다.
- 이미지 추출 중 프로그램이 멈춘 것처럼 보이는 문제를 줄이고, 저장 완료 후 진행창이 남는 문제를 보완했습니다.

3. 온맵 일괄 추출 안정성 개선
- 여러 온맵 PDF를 한 번에 이미지로 추출하는 기능을 보완했습니다.
- 같은 파일명이 있을 경우 자동으로 _2, _3 번호를 붙여 덮어쓰기를 방지합니다.
- 일부 문서나 일부 페이지에서 오류가 발생해도 전체 작업이 중단되지 않도록 개선했습니다.
- 저장 폴더 권한을 사전에 확인하도록 보완했습니다.
- 중복 추출 작업이 동시에 실행되지 않도록 안정성을 강화했습니다.

4. 확대/축소 사용성 개선
- Ctrl + 마우스 휠 확대/축소 동작을 더 부드럽게 개선했습니다.
- 확대/축소 중에는 기존 미리보기 이미지를 우선 부드럽게 표시하고, 조작이 끝난 뒤 최종 배율에서 다시 선명하게 렌더링되도록 개선했습니다.
- 대용량 PDF와 온맵 PDF에서 확대/축소 시 끊김을 줄이는 방향으로 보완했습니다.

5. PDF 미리보기 우클릭 메뉴 추가
- PDF 미리보기 화면에서 마우스 우클릭으로 주요 기능을 빠르게 확인하고 실행할 수 있습니다.
- 페이지 이동, 확대/축소, 현재 페이지 이미지 저장, 페이지 이미지 일괄 변환, 온맵 이미지 추출, 미리보기 갱신 등의 기능을 우클릭 메뉴에서 사용할 수 있습니다.

6. 일반 이미지 추출 안정성 개선
- 일반 PDF의 페이지 이미지 저장 및 내장 이미지 추출 후 진행창이 남는 문제를 보완했습니다.
- 저장 완료 후 완료 메시지와 화면 복귀 흐름을 정리했습니다.

7. 내부 구조 및 안정성 개선
- 온맵 이미지 추출, 미리보기, 확대/축소, 렌더링 관련 내부 구조를 정리했습니다.
- 대용량 PDF 처리 중 프로그램 응답성이 떨어지는 문제를 줄였습니다.
- 작업 중 오류가 발생했을 때 일부 작업이 전체 기능에 영향을 주지 않도록 예외 처리 흐름을 보완했습니다.

8. 보안 및 배포 정보 정리
- 프로그램 이름, 버전, 회사명, 실행 파일 정보 등 배포용 메타데이터를 정리했습니다.
- AhnLab 등 보안 프로그램의 평판 검토에 필요한 프로그램 정보와 파일 해시 생성 기준을 보완했습니다.
- 불필요한 과거 빌드 파일과 이전 검증 자료를 정리하여 배포 패키지를 간소화했습니다.

이번 v3.2.0은 특히 온맵 PDF를 사용하는 사용자를 위한 개선이 많이 포함된 버전입니다.
온맵 레이어 표시, 미리보기 갱신, 이미지 추출, 확대/축소 사용성이 v3.1.8보다 개선되었으므로 최신 버전 사용을 권장합니다.

업데이트 후 문제가 발생하면 사용 중인 PDF 파일 종류, 작업 내용, 오류 화면 또는 로그를 함께 전달해 주세요.
