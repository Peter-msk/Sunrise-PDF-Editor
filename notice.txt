[Sunrise PDF Editor v3.2.3 업데이트 안내]

v3.2.2에서 v3.2.3으로 업데이트되었습니다.

이번 v3.2.3은 v3.2.2의 여러 쪽 격자 모아보기, 좌측 패널 닫기/열기, 온맵 성능/확대·축소 개선 기능은 그대로 유지하면서, AhnLab 평판 검토와 Windows 파일 식별에 필요한 프로그램 정보/버전 리소스를 보정한 보안 식별정보 정리 버전입니다.

주요 업데이트
- Windows 실행파일 FixedFileInfo 보정: Sunrise_PDF_Editor.exe와 SunrisePDFEditorUpdater.exe의 filevers/prodvers를 3.2.3.0으로 일치시켰습니다.
- Native Render Host 리소스 보정: SunriseRenderHost.exe의 FILEVERSION/PRODUCTVERSION과 문자열 버전을 3.2.3.0으로 일치시켰습니다.
- AhnLab 제출 정보 보정: PROGRAM_INFORMATION.json, AhnLab 제출 패키지 생성 경로, 설치파일명, 제출 요청 문구를 v3.2.3 기준으로 정리했습니다.
- 검증 강화: check_program_identity_metadata.py가 문자열 버전뿐 아니라 FixedFileInfo 숫자 버전까지 확인하도록 보강했습니다.
- 배포 메타데이터 보정: latest.json, notice.txt, 설치파일명, Inno Setup 버전 정보를 v3.2.3 기준으로 맞췄습니다.

안내
- v3.2.2 사용자는 v3.2.3 설치를 권장합니다.
- 기능 동작은 v3.2.2와 동일하며, 이번 업데이트의 핵심은 프로그램 식별정보와 AhnLab 제출 자료 정합성 보정입니다.
- 설치 전 실행 중인 Sunrise PDF Editor를 종료한 뒤 진행해 주세요.
