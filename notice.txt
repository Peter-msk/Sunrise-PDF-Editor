[Sunrise PDF Editor v3.1.0 업데이트]

빌드 안정성, 빌드 실행성, 문법 오류, 코드 안전성, 보안정책 검사를 강화했습니다.
앱 시작/주기 자동 업데이트 확인 시 업데이트 승인 팝업은 띄우지 않고 하단 공지바와 상태바만 갱신하도록 조정했습니다.
업데이트 진행 창은 사용자가 업데이트 조회를 직접 누른 경우에만 표시됩니다.
latest.json/notice.txt/SHA256 메타데이터는 실제 릴리즈 빌드 완료 후 out 폴더에 자동 생성됩니다.

이번 버전은 최종 패키지 생성 전 빌드 안정성, 빌드 실행성, 문법 오류, 코드 안전성, 보안정책 검사를 강화했습니다.
설치파일 SHA256은 실제 릴리즈 빌드 완료 후 자동 계산되어 latest.json에 반영됩니다.
SunrisePDFEditorUpdater.exe는 Product ID, stable channel, Security Profile, Update Policy, SHA256 검증을 통과한 설치파일만 실행합니다.

앱 시작 시 자동 업데이트 확인으로 인한 별도 업데이트 팝업은 표시하지 않도록 조정했습니다.
업데이트가 있을 경우 하단 공지바에 안내하고, 사용자가 업데이트 조회를 직접 누를 때만 업데이트 진행 창을 표시합니다.
