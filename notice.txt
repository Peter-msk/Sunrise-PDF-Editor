[Sunrise PDF Editor v3.0.5 업데이트]

Sunrise Capture 방식에 맞춰 업데이트 조회 흐름을 보완했습니다.
새 버전이 있으면 GitHub latest.json을 기준으로 자동 확인합니다.
업데이트 조회를 누르면 공식 GitHub Releases의 NSIS 설치파일을 다운로드합니다.
다운로드가 완료되면 기존 프로그램을 정상 종료한 뒤 설치파일을 실행합니다.
하단 공지바는 notice.txt 변경 또는 업데이트 가능 여부가 있으면 "공지사항및 업데이트 내역이 있습니다."로 표시합니다.
변경사항이 없으면 "현재버전 3.0.5 / 최신버전 3.0.5" 형식으로 표시합니다.
회사 보안정책 준수를 위해 앱 런타임 PowerShell 실행, Registry 직접 조작, QSettings 저장은 사용하지 않습니다.
