# Sunrise PDF Editor

![Version](https://img.shields.io/badge/version-4.5.0-1668c7)

> **Sunrise Group의 Windows용 PDF 통합 편집 프로그램**  
> PDF 문서 열람부터 페이지 구성, 삽입·편집, 주석, 검색, 비교, 변환 및 출력까지 하나의 작업공간에서 수행할 수 있도록 설계되었습니다.

## 1. 프로그램 소개

**Sunrise PDF Editor**는 보고서, 도면, 제출 문서 등 다양한 PDF를 효율적으로 검토하고 편집하기 위한 데스크톱 프로그램입니다.

여러 개의 개별 도구를 오가는 대신, 리본 기반 작업공간에서 페이지 구조 변경과 문서 내용 검토, 편집 객체 추가, 결과물 정리를 연속적으로 진행할 수 있도록 구성했습니다.

특히 페이지가 많거나 도면·이미지·레이어가 포함된 PDF를 다루는 실무 환경을 고려합니다.

## 2. 주요 기능

### PDF 페이지 관리
- 여러 PDF 문서 병합 및 페이지 분할
- 페이지 삽입·복사·추출·삭제
- 페이지 순서 변경 및 회전
- 페이지 썸네일을 통한 탐색과 선택

### 삽입 및 편집
- 텍스트, 주석, 도형, 스탬프, 워터마크 등 삽입
- 편집 항목의 선택·이동·수정·삭제
- 정밀한 위치 조정 및 작업 취소
- 표 등 업무용 편집 객체 활용

### 보기 및 탐색
- 다중 문서 탭
- 확대·축소, 페이지 맞춤, 빠른 이동
- 페이지·레이어·작업 이력 등 보조 패널
- 리본형 도구와 문맥형 편집 UI
- 대형 PDF 및 도면형 PDF의 화면 확인을 고려한 작업공간

### 검색 및 문서 검토
- PDF 텍스트 검색
- 문서 및 페이지 비교 작업
- 주석·검토 정보 확인
- 문서 정보와 처리 결과 확인

### 변환 및 결과물 관리
- 이미지와 PDF 간 변환
- 다중 파일·페이지 단위 작업
- 결과물 저장 및 업무용 문서 정리

기능의 세부 제공 범위와 화면 구성은 설치된 버전에 따라 달라질 수 있습니다.

## 3. 작업 흐름

1. PDF 문서를 열고 페이지 썸네일과 문서 탭에서 작업 대상을 선택합니다.
2. 리본 메뉴에서 페이지 관리, 삽입·편집, 검색·검토 또는 변환 작업을 실행합니다.
3. 편집 결과를 화면에서 확인합니다.
4. 필요한 위치에 결과물을 저장하고 최종 PDF를 검토합니다.

사용자 문서와 기존 작업물의 보존을 우선하며, 중요한 파일 작업은 결과를 확인한 후 진행하는 것을 권장합니다.

## 6. 개발 방향

Sunrise PDF Editor는 기능 수를 늘리는 것뿐 아니라 실제 업무에서의 편집 완결성과 사용성을 높이는 데 중점을 둡니다.

- 대형·다중 페이지 PDF의 열람 및 반응성 개선
- 편집 화면과 저장된 결과물의 일치성 강화
- 페이지 작업·주석·양식 및 문서 비교 기능 개선
- 도면·이미지·레이어가 포함된 PDF 처리 안정화
- 반복 업무의 편의성과 오류 복구 경험 개선
- 다양한 화면 배율에서 리본과 편집 도구의 사용성 개선
