# Sunrise PDF Editor

> PDF 문서의 페이지 구성, 삽입·주석·편집, 변환, 검토, 비교 및 결과 출력을 하나의 작업공간에서 수행하기 위한 Windows PDF 통합 편집 도구

## 1. 프로그램 소개

Sunrise PDF Editor는 PDF 문서를 단순히 열어보는 뷰어가 아니라, 실제 보고서와 제출 문서를 정리하고 검토하는 데 필요한 작업을 하나의 데스크톱 작업공간으로 통합하기 위해 개발되었습니다.

페이지 병합·분할·삽입·삭제·추출·회전과 같은 문서 구조 작업, 텍스트·도형·주석·스탬프·워터마크·표 등의 삽입 작업, 문서 비교와 검색, 검토 결과 정리, 이미지와 PDF 간 변환, 대량 작업을 업무 흐름 중심의 리본 UI에서 수행할 수 있도록 설계합니다.

가장 중요한 원칙은 원본 PDF를 직접 훼손하지 않고, 모든 편집 결과를 별도의 출력물로 안전하게 생성하는 것입니다.

## 2. 개발 목적

1. 여러 프로그램에 나뉘어 있던 PDF 관련 업무를 하나의 작업대에서 처리합니다.
2. 페이지 단위 작업과 삽입 객체 단위 작업을 사용자가 눈으로 확인하면서 수행할 수 있게 합니다.
3. 대형 PDF와 복잡한 레이어 문서에서도 UI가 멈추지 않도록 렌더링과 처리 작업을 분리합니다.
4. 원본을 보존하고 저장 실패 시 불완전한 파일이 남지 않도록 원자적 출력 구조를 유지합니다.
5. 문서 보안 우회가 아니라 정상적인 편집·검토·변환 업무만 지원합니다.

## 3. 주요 기능

### 문서와 페이지 작업

- 여러 PDF 병합
- 문서 또는 선택 페이지 분할
- 다른 PDF의 페이지 삽입
- 빈 페이지 또는 작업용 페이지 생성
- 선택 페이지 삭제와 추출
- 페이지 회전과 순서 변경
- 문서 간 페이지 복사와 붙여넣기
- 페이지 썸네일을 이용한 빠른 이동과 선택
- 작업 이력과 실행 취소 흐름

### 삽입과 편집

- 텍스트, 주석, 도형, 스탬프, 워터마크, 표 등 업무용 객체 삽입
- 삽입한 항목의 선택, 이동, 수정, 다중 선택 삭제
- 방향키를 이용한 정밀 위치 이동
- 선택 항목에 맞는 문맥형 미니 도구막대
- 표 모델을 저장한 뒤 다시 열어 재편집하는 흐름
- 실제 PDF에 표시 가능한 결과가 생성되었는지 확인한 후 성공 처리

### 보기와 탐색

- 다중 문서 탭
- 확대·축소와 페이지 맞춤
- 좌측 페이지·레이어·작업이력 패널
- 우측 작업 도구·문서 정보·기능 설명 패널
- `Alt+/` 기반 도구 검색
- 리본 표시·숨김과 작업공간 설정 기억
- 대형 문서 렌더링을 위한 지연 초기화와 Worker 분리

### 검색·검토·비교

- PDF 텍스트 인덱스와 검색
- 텍스트 추출 상태와 OCR 필요 여부 진단
- PDF 문서 또는 페이지 비교 업무 지원
- 주석·검토 목록과 결과 리포트 정리
- 검토 패키지 및 작업 매니페스트 생성
- 문서 정보와 처리 결과 확인

### 변환과 대량 작업

- 이미지와 PDF 간 변환
- 여러 파일 또는 페이지에 대한 반복 작업
- 처리 대상과 결과를 구분하는 대량 작업 흐름
- 온맵 및 대용량 레이어 PDF를 고려한 안정 처리 경로
- 결과 파일과 관련 보고서를 지정 출력 폴더에 별도 생성

## 4. 사용자 작업공간

Sunrise PDF Editor의 상단 업무 탭은 다음 흐름을 기준으로 구성됩니다.

```text
파일 | 홈 | 보기 | 주석 | 편집 | 페이지 | 양식 | 보안 | 도움말
```

핵심 기능은 큰 아이콘으로, 보조 기능은 컴팩트한 명령으로 배치하며, 좌측 페이지 패널·중앙 PDF 캔버스·우측 작업 패널이 하나의 작업공간으로 연결됩니다.

## 5. 원본 보호와 안전 정책

- 원본 PDF를 직접 덮어쓰지 않습니다.
- 결과는 사용자가 선택한 경로에 새 파일로 저장합니다.
- 저장 중 오류가 발생하면 기존 정상 파일을 훼손하지 않는 원자적 출력 방식을 우선합니다.
- PDF 암호 제거, DRM 우회, 복사방지 해제, 보호 권한 무력화 기능은 포함하지 않습니다.
- OCR 실행 기능은 현재 핵심 편집 기능과 분리하며, 문서의 텍스트 상태와 OCR 필요 여부를 진단하는 방향을 유지합니다.
- 사용자의 문서 본문과 작업 파일을 자동으로 외부 서버에 전송하지 않습니다.

## 6. 개발 방향

Sunrise PDF Editor는 범용 기능의 개수를 늘리는 것보다 실제 문서 업무의 완결성과 신뢰성을 높이는 방향으로 개발합니다.

- 대형·다중 페이지 PDF의 렌더링 속도와 메모리 사용 최적화
- 삽입 객체의 화면 표시와 실제 저장 결과 일치성 강화
- 페이지 편집, 렌더링, 작업 이력, 저장 엔진의 모듈 경계 강화
- 문서 비교와 검토 리포트의 실무 활용도 향상
- 반복 작업을 재사용할 수 있는 워크벤치 매니페스트와 작업 프리셋 강화
- 양식과 주석 객체의 호환성 확대
- 온맵·도면·대형 이미지 PDF의 안정적인 미리보기 및 내보내기 개선
- 장애 발생 시 작업 복구와 세션 복원 기능 강화
- 100%, 125%, 150% DPI에서 리본과 작업 패널의 가독성 유지
- 실행형과 설치형의 안전한 업데이트 및 Sunrise Group 서명 체계 유지

## 7. 지원 환경과 배포

- 대상 운영체제: Windows 10/11 64비트
- 배포 형태: 포터블 실행형 패키지 또는 설치형 Setup
- 현재 공개 README 작성 기준: Sunrise PDF Editor v4.0.1
- 공식 기준 UI: 리본 기반 통합 작업공간
- 현재 기능 구성은 릴리즈 버전에 따라 일부 차이가 있을 수 있습니다.

## 프로젝트 공통 원칙

Sunrise Group의 프로그램은 단순한 일회성 스크립트가 아니라 실제 업무에서 반복 사용할 수 있는 Windows 데스크톱 도구를 목표로 합니다.

- 원본 파일과 사용자 데이터를 우선적으로 보호합니다.
- 삭제, 다운로드, 업데이트, 외부 프로그램 실행 등 중요한 동작은 사용자가 인지하고 승인한 경우에만 수행합니다.
- 사용자 문서, 이미지, 프로젝트 데이터와 API 키를 불필요하게 외부로 전송하지 않습니다.
- 장시간 작업은 진행 상태와 현재 처리 단계를 표시하고, 오류 발생 시 사용자용 안내와 진단 로그를 분리합니다.
- 공식 배포본은 제품 정보, SHA-256 무결성 확인, 코드 서명, AhnLab/V3 사전점검 등 Sunrise Group의 배포 기준을 따릅니다.
- 기능 추가보다 기존 기능의 재현성, 복구 가능성, 대용량 처리 안정성, 유지보수성을 우선합니다.
