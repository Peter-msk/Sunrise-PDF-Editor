# Sunrise PDF Editor

Sunrise Group의 업무용 PDF 문서 열람·편집 프로그램입니다.

## 프로그램 목적

PDF 보고서와 제출 문서, 도면 자료를 한 작업공간에서 검토하고 페이지 구성·주석·편집·저장을 수행하여 문서 처리 작업을 간소화합니다.

## 지원 운영체제

- Windows 10 / Windows 11 (64비트, x64)

## 개발언어 및 주요 기술

- **개발언어:** Python
- **주요 기술:** PDF 문서 렌더링·편집 처리 및 Windows 데스크톱 UI
- **배포 형태:** Windows 설치형 프로그램

## 주요 기능

- PDF 열기, 다중 문서 탭과 페이지 썸네일 탐색
- 페이지 삽입·복사·추출·삭제·회전·순서 변경
- PDF 병합 및 분할
- 텍스트, 도형, 주석, 스탬프, 워터마크 등 편집 도구
- 문서 내 검색, 확대·축소 및 페이지·레이어 검토
- 문서·페이지 비교와 PDF/이미지 변환
- 편집 결과 저장 및 재열기를 통한 문서 확인
