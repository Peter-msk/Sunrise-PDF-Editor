# Sunrise PDF Editor

Sunrise Group의 Windows 업무용 PDF 열람·편집·검토·변환 프로그램입니다. 일반 문서와 대형 도면·온맵 PDF를 하나의 작업공간에서 다루며, **원본 보존·결과 검증·작업 복구**를 중시합니다.

## 제품 정보

- **제품 버전:** 4.6.0
- **최종 내부 개발 기준본:** R32 (2026-11-01)
- **운영체제:** Windows 10 / 11, 64비트(x64)
- **주요 기술:** Python 3.12, PySide6(Qt), PyMuPDF/MuPDF, PDFium 및 C++17 Native 렌더링, Pillow 등
- **배포 형태:** Windows 데스크톱 설치형
- **운영 판정:** 사용자 Windows 실무 검증 완료(사용자 보고 기준). 대외 상용 배포·공식 자동 업데이트는 별도 인증 전까지 보류.

## 프로그램 주요 편의기능

- **다중 문서 탭:** 여러 PDF를 열어 이동하며 작업. 긴 문서명은 화면 너비에 맞게 줄여 표시하고 전체 이름을 확인할 수 있습니다.
- **유연한 작업 패널:** 좌측 OCG 레이어·우측 빠른 작업을 기본 제공하며, 필요에 따라 패널을 추가·삭제·접거나 다시 펼칠 수 있습니다. 빈 패널은 불필요하게 넓어지지 않도록 제한합니다.
- **페이지 썸네일 탐색:** 공간에 따라 여러 열로 배치하며, 페이지 이동·선택·회전·순서 변경을 지원합니다.
- **하나의 실무 작업센터:** 변환, 일괄 처리, 압축, 분할, 스캔 보정, 비교 등 자주 쓰는 문서 작업으로 빠르게 진입할 수 있습니다.
- **한글 중심 UI:** 공통 확인·경고 창, 긴 파일명·경로 표시, 명확한 저장·종료 동작으로 실무 혼동을 줄입니다.
- **문서 원본 보호:** 가능하면 원본과 별도로 결과를 저장하고, 충돌·실패 시 임의 덮어쓰기 대신 안전하게 중단·복구합니다.
- **Undo·세션 복원:** 지원되는 편집은 되돌리기를 제공하며, 저장 실패나 종료 취소 시 미저장 작업을 보호합니다.
- **대형 도면·온맵 검토:** Native PDFium 타일 렌더링, OCG 레이어 켜기·끄기, 캐시 기반 확대·이동 기능을 제공합니다.
- **출력 결과 확인:** 병합·압축·추출 등 주요 결과물을 재열어 텍스트·페이지·링크·주석·레이어 보존 여부를 확인하도록 설계했습니다.
- **업데이트 안내:** Sunrise Control v1 정책에 따라 신규 버전이 확인되면 기존 필수 업데이트 결정 흐름을 사용합니다.
