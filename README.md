# Sunrise PDF Editor

**최신 배포 기준: v4.5.0** · Windows 10/11 x64 · 설치형

보고서·도면·제출 문서의 PDF를 열람하고 페이지 구성, 편집, 주석, 검색, 비교 및 저장 작업을 수행하는 Sunrise Group의 Windows용 PDF 편집 프로그램입니다.

## 1. 프로그램 개요
Sunrise PDF Editor는 PDF 문서를 여러 도구로 옮기지 않고 하나의 리본 기반 작업공간에서 검토·편집·저장하기 위한 데스크톱 애플리케이션입니다. 페이지가 많은 문서와 이미지·도면이 포함된 문서의 실무 사용을 고려합니다.

## 2. 개발 목적
- 문서 열람과 페이지 편집을 하나의 흐름으로 연결합니다.
- PDF 검토 시 필요한 주석·삽입·검색 도구를 통합합니다.
- 편집한 내용과 실제 저장 결과를 확인하기 쉽게 구성합니다.
- 업무용 제출 문서의 반복 편집과 정리 시간을 줄입니다.

## 3. 주요 기능
- PDF 열기 및 다중 문서 탭
- 페이지 썸네일 탐색, 삽입·복사·추출·삭제·회전·순서 변경
- PDF 병합과 분할
- 텍스트·도형·주석·스탬프·워터마크 등 편집 요소 추가
- 페이지·레이어 및 작업 이력 패널
- 확대·축소, 화면 맞춤, 문서 내 텍스트 검색
- 문서와 페이지 비교·검토
- PDF/이미지 간 변환 및 결과물 저장

세부 도구의 지원 범위는 사용 중인 설치 버전 및 PDF 문서 특성에 따라 달라질 수 있습니다.

## 4. 실행조건
| 항목 | 조건 |
| --- | --- |
| 운영체제 | Windows 10 또는 Windows 11 |
| 시스템 | 64비트(x64) |
| 배포 형식 | Setup EXE 설치형 |
| 대상 문서 | PDF 및 프로그램에서 지원하는 이미지 형식 |
| Python 설치 | 공식 설치본 사용에는 필요 없음 |

## 5. 설치 및 사용방법
1. [공식 릴리즈](https://github.com/Peter-msk/Sunrise-PDF-Editor/releases)에서 Sunrise PDF Editor용 설치파일을 내려받아 설치합니다.
2. 프로그램 실행 후 PDF를 엽니다.
3. 문서 탭과 페이지 썸네일에서 작업할 문서·페이지를 선택합니다.
4. 리본 메뉴에서 페이지 관리, 삽입·편집, 검색·검토, 변환 기능을 선택합니다.
5. 변경 결과를 화면에서 확인한 다음 필요한 위치에 저장합니다.
6. 최종 PDF를 다시 열어 페이지 구성과 편집 결과를 확인합니다.

중요한 원본 문서는 별도 사본으로 보관하는 것을 권장합니다.
